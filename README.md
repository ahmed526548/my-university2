## RestaurantOS

منصة عربية لإدارة المطاعم والطلبات والمبيعات مبنية باستخدام React وVite.

### التشغيل
- npm install
- npm run dev
- npm run build

### الوحدات في نسخة MVP
- لوحة مؤشرات وإدارة الطلبات.
- شاشة مطبخ وتحديث حالة الطلب.
- منيو عميل وسلة طلب.
- إدارة منتجات ومخزون.
- إدارة طاولات وواجهة QR تمهيدية.
- تقارير وملخص خزينة.

### تنبيه مهم
هذه نسخة عرض أولية ببيانات تجريبية داخل ذاكرة التطبيق. لا توجد قاعدة بيانات دائمة أو تسجيل دخول وصلاحيات حقيقية أو بوابة دفع إلكتروني أو QR فعلي بعد. يلزم ربط Backend آمن، قاعدة بيانات، مصادقة وصلاحيات، تحقق دفع من الخادم، واختبارات قبل استخدامها في مطعم حقيقي.
